# Madhavan.website

Personal website for showcasing projects.

## Run locally

Because this is a static website, you can run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Important asset

Place your portrait at:

- `assets/my-face.jpg`

The page is already wired to use this image in both parallax sequences. If missing, a visual fallback is shown.
